- [ ] **Camera vendor:** contract + purpose limitation (no ANPR/faces unless separately approved); vendor DPA if processing personal data
- [ ] Confirm demo data remains synthetic / inspector-paired counts only until the above are signed
- [ ] No plates, faces, or device IDs in exports shared outside the pilot team
