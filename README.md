# ParkWiz

- **What:** ParkWiz — parking occupancy detection from existing city CCTV footage, with [no new hardware needed](./PILOT_README.md).
- **For whom:** municipalities, smart city developers, urban planners.
- **How:** browser-based demo using local video frames — [no server](./factory/EVIDENCE/current-state-audit.md), [no license plates](./PILOT_README.md).

## [🚗 לדמו החי של ParkWiz](https://swissystem7.github.io/ParkWiz/)

ParkWiz הוא שוק להזמנת חניות פרטיות ליד היעד, שמחבר נהגים עם בעלי חניה בשעות שבהן המקום פנוי.

הועלה מהמחשב של אבירן — יולי 2026.
