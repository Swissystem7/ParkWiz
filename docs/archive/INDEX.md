# ארכיון מסמכים — היסטורי בלבד

הקבצים כאן **אינם** מקור האמת. מה שהמוצר היום, מה הפיבוט, ומה מותר להבטיח — רק ב-[README.md](../../README.md) ובמחקר העדכני [RESEARCH.md](../../RESEARCH.md).

שום דבר בתיקייה הזו לא רץ באתר החי ולא נטען מ-`index.html`.

| קובץ | למה הוא כאן |
|---|---|
| `HACKATHON.md` | פיץ' האקתון כמרקטפלייס לחניות פרטיות — זהות שנפסלה במחקר. |
| `PILOT_README.md` | מתאר צינור `frame-grabber.js` → `vision-bridge.js` וקבצים שלא היו בריפו. |
| `RESEARCH.pre-pivot-2026-08.md` | מחקר שוק ישן יותר (לפני פסק דין PIVOT מ-13.8.2026). |
| `SPEC-v2-municipal-integration.md` | מפרט יולי 2026 עם הנחות (פנגו API, קואורדינטות ת״א) שלא תואמות את הדמו/הפיבוט. |
| `TASKS.md` | תור משימות לסוכן Ollama מקומי — לא רלוונטי למוצר החי. |
| `TEST_EVIDENCE.md` | יומן בדיקות יולי 2026, כולל קבצי `tlv-*.json` שכבר לא בריפו. |
| `_pw_patch.js` | סקריפט חד-פעמי שערך את `index.html`; כבר הוחל. |
| `factory/` | ביקורת מצב ועותקי עזר ישנים; לא קוד שרץ ב-Pages. |

`VALIDATION.md` וקאש graphify **לא נמצאו** בעץ בזמן הארכיון. לא נמחק שום דבר שיש לו היסטוריה שימושית — רק הועבר לכאן.
