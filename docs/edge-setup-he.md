# התקנת קופסת הקצה של ParkWiz (Frigate + go2rtc)

מדריך התקנה למחשב מיני באתר — או לשרת ה-Lenovo לצורכי בדיקה. הקופסה קוראת את
המצלמות הקיימות של החניון דרך RTSP, מזהה רכבים לכל חניה, ומעדכנת את ParkWiz
בזמן אמת. **הווידאו לא יוצא מהאתר.** מה שיוצא מהקופסה אל הדפדפן הוא שורה אחת
לכל שינוי: `{lot, spotId, occupied, ts}`.

רלוונטי ל-#266 (EPIC #265, שורות 3, 6, 14). הקבצים: `edge/`.

## 1. מה צריך

| | מינימום | מומלץ |
|---|---|---|
| מחשב | 4 ליבות, 8GB RAM, SSD 128GB | Intel i5 מדור 8 ומעלה (iGPU ל-ffmpeg) |
| מערכת | Debian 12 / Ubuntu 22.04 עם Docker | אותו דבר + UPS קטן |
| רשת | כבל LAN לאותו VLAN של המצלמות | VLAN מצלמות נפרד + חוק מעבר יחיד |
| מצלמות | RTSP (Hikvision / Dahua / כל NVR) | sub-stream ‏704x576 ומעלה, 5fps |

מספר מצלמות לקופסה: עד 4 זרמי sub-stream על זיהוי CPU. מעבר לכך — להוסיף
Google Coral TPU (‏`type: edgetpu` ב-`edge/frigate/config.yml`).

## 2. התקנה

```bash
# 1. Docker (אם עוד לא מותקן)
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker "$USER"   # צריך logout/login

# 2. הקבצים
git clone https://github.com/Swissystem7/ParkWiz.git
cd ParkWiz/edge

# 3. סודות — מקומי בלבד, לא נכנס ל-git
cp .env.example .env
chmod 600 .env
nano .env        # CAM_USER / CAM_PASSWORD / CAM_HOST

# 4. כתובת ה-LAN של הקופסה, ל-WebRTC
ip -4 addr show | grep inet        # ואז לעדכן webrtc.candidates ב-go2rtc.yaml

# 5. הרמה
docker compose up -d
docker compose logs -f frigate     # לוודא שהזרם נקרא ושאין שגיאת אימות
```

בדיקה שהזרם עובד: `http://<ip-של-הקופסה>:1984` — ממשק go2rtc, לוחצים על
`lot_cam` ← `stream`. אם רואים תמונה, שאר השרשרת היא קונפיגורציה בלבד.

## 3. סימון החניות (zones)

כל חניה היא zone אחד ב-Frigate. זה החלק שדורש אדם באתר פעם אחת:

1. נכנסים ל-`http://127.0.0.1:5000` בקופסה עצמה (או דרך מנהרת SSH).
2. Settings ← Zones ← מסמנים מרובע על החניה הראשונה.
3. שם ה-zone הוא **מפתח החיבור** ל-ParkWiz. שומרים על התבנית
   `<lot>_<bay>`, למשל `atidim_a01`, כדי ששני חניונים על אותה קופסה לא יתנגשו.
4. מעתיקים את שורת ה-`coordinates` לתוך `edge/frigate/config.yml`.
5. מוסיפים את אותו שם ב-`edge/bridge/config.json` מול מספר החניה שהנהג רואה:
   `"atidim_a01": "A-01"`.

שתי הטעויות הנפוצות:

* **מרובע גדול מדי** — רכב בנתיב הנסיעה "ממלא" את החניה. לסמן את הצבע על
  האספלט, לא את השוליים.
* **שם zone שלא תואם** בין שני הקבצים — החניה פשוט לא תתעדכן, בשקט.
  `npm test` חוסם את זה: `test/edge-config.test.js` משווה את שני הקבצים.

## 4. הגשר (bridge) ו-ParkWiz

הגשר נרשם ל-MQTT של Frigate ומוציא ל-ParkWiz הודעות JSON בלבד — אין בהן תמונה,
אין מספר רישוי, אין זיהוי נהג (`src/lib/edge-bridge.js`, רשימת מפתחות סגורה):

```json
{"type":"spot","lot":"atidim","spotId":"A-01","occupied":true,"ts":"2026-10-19T09:00:00.700Z"}
{"type":"spot-freed","lot":"atidim","spotId":"A-01","ts":"2026-10-19T09:14:02.100Z"}
{"type":"health","camera":"lot_cam","state":"frozen","ok":false,"warningHe":"..."}
```

בדף ParkWiz: הגדרות ← **מקור חי** ← להקליד את כתובת הגשר
(`http://<ip-של-הקופסה>:8787`). אין להקליד סיסמה בכתובת — הדף דוחה כתובת
שמכילה אחת. אם אין גשר, או שהגשר שותק יותר מ-10 שניות, הדף חוזר מעצמו לזיהוי
בדפדפן (#264) ואומר זאת על המסך — עדיף זיהוי מקומי על מסך שמציג תמונת מצב
מתה כאילו היא חיה.

## 5. בריאות המצלמה

הקופסה מדווחת שתי תקלות, והן מופיעות כאזהרה בדף:

| מצב | מה קרה | מה עושים |
|---|---|---|
| `offline` | Frigate לא מדווח פריימים (‏`camera_fps = 0`) או שקט מעל 15 שניות | לבדוק חשמל/כבל למצלמה, ואז `docker compose restart go2rtc` |
| `frozen` | פריימים מגיעים אבל שום דבר לא זז מעל 2 דקות — החתימה של זרם תקוע | לפתוח את התמונה ב-go2rtc; אם היא קפואה, לאפס את המצלמה |

חניה לא "נתקעת" על ירוק בשקט: ברגע שהמצלמה שלה לא בריאה, האזהרה על המסך.

## 6. בדיקת קבלה בלי מצלמה באתר

אפשר להוכיח את כל השרשרת על שרת הבדיקות, עם קליפ מוקלט שמוגש כ-RTSP אמיתי:

1. לשים קליפ חניון ב-`edge/samples/sample-lot.mp4` (התיקייה לא נכנסת ל-git).
2. ב-`edge/frigate/config.yml` להפנות את `lot_cam` אל
   `rtsp://127.0.0.1:8554/demo_cam` — הזרם המוכן ב-`go2rtc.yaml` שמנגן את
   הקליפ בלופ.
3. `docker compose up -d` ואז לסמן zones על התמונה הזאת.
4. לפתוח את ParkWiz עם כתובת הגשר. רכב שיוצא בקליפ צריך להפוך את החניה
   לירוקה על המסך בתוך **כ-2 שניות**: ההשהיה היחידה שהגשר מוסיף היא חלון
   הייצוב (`holdMs`, ברירת מחדל 700ms, חסום ל-1500ms).

## 7. צ'ק-ליסט ל-IT של החניון

להעביר לאיש ה-IT לפני ההתקנה. שלושת הראשונים הם תנאי, לא המלצה:

- [ ] **משתמש RTSP לקריאה בלבד** למצלמות/ל-NVR (Hikvision: Operator עם
      Live View + Playback בלבד; Dahua: קבוצה עם Monitor בלבד). ללא הרשאת
      PTZ, ללא שינוי הגדרות, ללא מחיקת הקלטות, ללא ניהול משתמשים.
- [ ] **אין פתיחת פורט נכנס מהאינטרנט** לקופסה ולמצלמות. אין port forwarding,
      אין UPnP, אין DDNS, אין P2P/ענן של היצרן. גישה לתחזוקה — דרך VPN או
      מנהרת SSH של החניון.
- [ ] **הווידאו לא יוצא מהאתר.** ההקלטה והתמונות כבויות ב-Frigate
      (`record.enabled: false`, `snapshots.enabled: false`), ו-MQTT מאזין
      בתוך הקופסה בלבד. מה שעובר ב-LAN: JSON של תפוסה.
- [ ] הקופסה על אותו VLAN של המצלמות, או עם חוק מעבר יחיד
      ‏(קופסה ← מצלמות, פורט 554 בלבד).
- [ ] כתובת IP קבועה לקופסה (DHCP reservation) — כתובת הגשר מוקלדת בדף.
- [ ] שעון מסונכרן (NTP) בקופסה ובמצלמות; חותמות הזמן של התפוסה נשענות עליו.
- [ ] `edge/.env` בהרשאות `600`, בבעלות המשתמש שמריץ את Docker. הסיסמה לא
      נשלחת במייל/וואטסאפ ולא נכנסת ל-git.
- [ ] עדכוני אבטחה לקופסה (`unattended-upgrades`) ו-UPS קטן, כדי שאתחול
      חשמל לא ישאיר את החניון בלי נתונים.

## 8. פרטיות — מה הקופסה לא עושה

אין זיהוי מספרי רישוי, אין זיהוי פנים, אין מעקב אחרי אדם, אין שמירת תמונות,
אין שמירת וידאו, אין אודיו. Frigate מזהה *מחלקת אובייקט* (`car`, `truck`,
`bus`, `motorcycle`) ומוציא ספירה לכל zone; `person` לא מופיע בהגדרות הזיהוי
כאן. ההודעה שיוצאת מהגשר עוברת דרך רשימת מפתחות סגורה, ולכן גם מנוי שיירשם
ל-`frigate/#` לא יקבל תמונה דרך ParkWiz — נושאי ה-`snapshot`/`clip`/
`thumbnail` נדחים מראש. ראו גם `pilot-privacy.html`.
