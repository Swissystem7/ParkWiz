# פיילוט פארק עתידים — זרימה אחת

הדף הזה הוא מקור האמת ל**זרימה המאוחדת** של הפיילוט: מצלמה אחת, מנוע תפוסה אחד, באס אירועים אחד, והנהג בסוף. עד #268 כל חלק היה עומד בפני עצמו (דמו המצלמה, לוח המפעיל, התראת נהג שהייתה רק משפט בפיץ׳). עכשיו יש מסלול אחד.

| | |
|---|---|
| **הדף** | [demo/pilot.html](../demo/pilot.html) — עברית RTL, ארבעה משטחים בדף אחד |
| **הספרייה** | [src/lib/pilot-flow.js](../src/lib/pilot-flow.js) — באס, מקורות, הגדרות, התראה והחזקה. ללא DOM, ללא תלויות |
| **מנוע התפוסה** | [src/lib/atidim-lot.js](../src/lib/atidim-lot.js) — `calculateOccupancy`. המספרים לא מחושבים שוב בשום מקום אחר |
| **קליפ הדוגמה** | [pilot/sample-clip.json](../pilot/sample-clip.json) — 24 תאים, פריים כל שתי שניות |
| **בדיקות** | `npm test` → [test/pilot-flow.test.js](../test/pilot-flow.test.js) (הספרייה) · [test/pilot-e2e.test.js](../test/pilot-e2e.test.js) (קליפ → התראה, על הדף עצמו) |

## הזרימה

```
מקור מצלמה            →  מנוע תפוסה        →  באס אירועים         →  משטחים
sample / browser         calculateOccupancy    occupancy              נהג (התראה + ניווט + החזקה)
frigate                  (atidim-lot.js)       spot-freed             מנהל חניון (מדדים + יומן)
                                               driver-alert           שלט כניסה (מספר אחד)
                                                                      הגדרות (מקור אחד לכולם)
```

כל פריים נכנס ב־`flow.ingest(frame)` ויוצא כאירועים על הבאס. שום משטח לא מחשב תפוסה בעצמו — שלט הכניסה מציג את אותו מספר שהמנהל רואה, וההתראה לנהג נולדת מאותו `spot-freed`.

**התפנה תא = מעבר תפוס→פנוי של תא שהמצלמה כבר דיווחה עליו.** פריים ראשון אחרי טעינה או אחרי החלפת מקור הוא *התחלה קרה*: אין השוואה, ולכן אין התראה. בלי הכלל הזה החלפת מצלמה הייתה ממציאה עשרות „יציאות” שלא קרו.

## ארבעת המשטחים (ניווט אחד)

הניווט נגזר מ־`ParkWizPilotFlow.SURFACES`, ולכן הוא קיים פעם אחת בקוד:

| משטח | כתובת | מה רואים |
|------|-------|----------|
| **נהג** | `demo/pilot.html#driver` | כרטיס התראה: איזה תא התפנה, כמה זמן הוא מוחזק, וכפתור ניווט לחניון |
| **מנהל חניון** | `#manager` | פנוי / תפוס / אחוז תפוסה / עמדות טעינה פנויות + יומן התאים שהתפנו |
| **שלט כניסה** | `#sign` | מספר אחד ומילה אחת, לקריאה מרכב מתקרב. „מלא” במקום 0 |
| **הגדרות** | `#settings` | מקור המצלמה, כתובת גשר Frigate, משך ההחזקה, והתראות על עמדות טעינה בלבד |

## מקורות מצלמה

שלושה מקורות, רשומים פעם אחת ב־`SOURCES`:

- **`sample` — קליפ דוגמה (ברירת מחדל).** `pilot/sample-clip.json`: שורה של 0/1 לכל תא, פריים כל שתי שניות. זה הפלט *המפוענח* של מצלמת שער — לא וידאו, לא תמונות, ולא לוחיות. בגלל זה אותה זרימה רצה ב־CI בלי דפדפן וגם בחניון בלי רשת.
- **`browser` — מצלמת הדפדפן (#264).** המצלמה של המכשיר שמציג. דורשת אישור מצלמה; הפריים לא יוצא מהמכשיר.
- **`frigate` — גשר Frigate / NVR (#266).** מתחבר ל־Frigate או ל־NVR שבשער ברשת המקומית. דורש כתובת בסיס, שנשמרת בהגדרות.

החלפת מקור מאפסת את הזרימה (`flow.reset()`) ומוחקת התראה פעילה.

## החזקה (hold) ורכב חשמלי

- משך ההחזקה נקבע בהגדרות, בין 30 ל־600 שניות (ברירת מחדל 120).
- הכרטיס מציג ספירה לאחור, ובסוף „ההחזקה פגה — התא שוחרר לנהג הבא”. אפשר לשחרר מוקדם.
- הנוסח נשאר באותו רגיסטר של [src/lib/margin.js](../src/lib/margin.js): **חיזוי, לא הבטחה**. החזקה היא חלון נימוס שהמפעיל נותן, לא תא ששמור לנצח.
- „התראות על עמדות טעינה בלבד” מסנן את `spot-freed` לתאי טעינה (`evBays` בקליפ), כדי שרכב חשמלי מחובר לא יישלח לתא רגיל.

## פרטיות

אין לוחיות רישוי, אין זיהוי פנים, ואין וידאו שנשמר — גם לא בפיילוט עצמו. מה שיוצא מהמצלמה בכל פריים הוא 24 ספרות של תפוס/פנוי, וזה בדיוק מה שיש בקליפ הדוגמה שבריפו. ההגדרות נשמרות ב־`localStorage` של המכשיר בלבד (`parkwiz.pilot.v1`).

## להרצה בפגישה (ללא רשת)

1. לפתוח את [demo/pilot.html](../demo/pilot.html) פעם אחת **עם** רשת — ה־Service Worker שומר את הדף, הספריות והקליפ (`parkwiz-field-v19`).
2. מכאן והלאה הדף עובד גם במטוס: „הפעל את הקליפ”, ואז לעבור בין המשטחים בניווט העברי.
3. הסדר שעובד מול לקוח: **שלט כניסה** (מה שהנהג רואה בשער) → **נהג** (ההתראה כשתא מתפנה) → **מנהל חניון** (אותם מספרים + יומן) → **הגדרות** (מכאן מתחברים למצלמה האמיתית).
4. תסריט הפגישה המלא, כולל שאלות צפויות: [docs/launch/CITYZONE-ATIDIM.md](./launch/CITYZONE-ATIDIM.md) ו־[docs/CITYZONE_ATIDIM_PITCH.md](./CITYZONE_ATIDIM_PITCH.md).

## מה עוד לא כאן

- `browser` ו־`frigate` נבחרים ונשמרים בהגדרות, אבל הזרימה עדיין מוזנת מקליפ הדוגמה: חיבור `getUserMedia` (#264) והגשר ל־Frigate (#266) נכנסים כ־PR נפרד כל אחד, ושניהם מזריקים פריימים לאותו `flow.ingest`.
- שני דפי הדמו הקודמים נשארים: [demo/atidim.html](../demo/atidim.html) (פריים + שכבת זיהוי) ו־[demo/atidim-board.html](../demo/atidim-board.html) (מפת חניון ומחוון שעה). הם תשובות למצלמה ולסקירת היום; הזרימה המאוחדת היא הכניסה אליהן.
- **דוח ה-KPI של הפיילוט** נשאר ב-[pilot-report.html](../pilot-report.html) (דיוק מול פקח, עקומה, מפת חום). „העתק תקציר מדדים” במשטח המנהל מייצר את השורה שנכנסת לשם — הזרימה לא מדפיסה דוח בעצמה.
- אין דיוק שדה נמדד. הקליפ והמודל השעתי מסומנים `sample` / `synthetic`.
