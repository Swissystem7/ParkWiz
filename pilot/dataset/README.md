# מערך דמו להערכת היוריסטיקה

הסצנות כאן **מסונתזות בריפו**. הן לא צילום ממצלמת עירייה ולא ספירת פקח.

## מה יש

- `manifest.json` — קטלוג הסצנות והתוויות.
- `labels.json` — לכל סצנה אילו מקומות תפוסים (אינדקס 0–11, אותה פריסה כמו `sample-spots.json`).
- קבצי SVG בתיקיית `pilot/` (`sample-lot.svg`, `sample-empty.svg`, וגרסאות לילה / דמדומים / רטוב / רכב בהיר).

## איך מריצים בלי מצלמה

1. בדפדפן: [דיוק דמו](../../pilot-eval.html) — מריץ את המחולל ואת שני האלגוריתמים באותו רגע.
2. במסוף: `npm test` — `test/dataset.test.js` נועל שהמספרים מסומנים synthetic וש־v2 טוב מ־v1 על הסט הזה.

## מה המספר אומר

הסכמה מול התוויות שציירנו במחולל (`src/lib/dataset.js`). זה לא דיוק שדה. דיוק מול פקח בנתניה עדיין לא נמדד.
